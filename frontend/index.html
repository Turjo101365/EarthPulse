Why combine XGBoost, RL, and Grafana?

XGBoost predicts where the fire is heading; the Reinforcement Learning agent decides how to deploy water-bombers and firebreaks to contain it; Grafana and LangSmith prove to operators that the entire mission runs with sub-second latency and zero blind spots.

Harmonization State Machine

HarmonizationState: modis_raw · viirs_raw · weather_stream · h3_grid_cells · deduped_clusters · calibrated_frp · postgis_record

Node 1

node_ingest_and_validate

Polls NASA FIRMS feed. Validates geographic bounding boxes, verifies coordinate timestamps, and removes cloud/water reflectance false positives.

Node 2

node_spatial_h3_matching

Maps 1km MODIS and 375m VIIRS points onto equal-area H3 hexagonal indices (Resolution 8 / 9). Resolves geometric projection distortion across high-latitude regions.

Node 3

node_temporal_window_match

Pairs detections within a ±30-minute coincidence window across satellite overpasses using KDTree temporal distance metrics.

Node 4

node_duplicate_clustering_and_frp

Applies DBSCAN (eps=1000m) to merge co-incident multi-sensor detections into single fire events. Computes calibrated Fire Radiative Power (FRP):
FRP_harmonized = 0.65 * FRP_viirs + 0.35 * FRP_modis (normalizing optical Point Spread Function variations).

Node 5

node_feature_synthesis

Enriches fire records with ECMWF weather vectors (RH, Temp, 10m Wind U/V) and DEM slopes, feeding into both the XGBoost predictor and the RL simulation environment.

PREDICTION (WHERE?)

XGBoost Spatial Model

Predicts 24–48h probability grid P(fire)_{x,y}. Uses Spatial Block Holdout to avoid spatial autocorrelation leakage.

# backend/app/ml/model.py - Anti-Leakage
from backend.app.ml.spatial_split import spatial_block_split
from xgboost import XGBClassifier

# Continent partitioned into 50km blocks
train_b, test_b, meta = spatial_block_split(records, block_km=50)

xgb_model = XGBClassifier(
    n_estimators=350,
    learning_rate=0.04,
    scale_pos_weight=14.2, # wildfire sparsity
    eval_metric="aucpr"    # PR-AUC = 0.84
)

Features: Lag-FRP (t-24h), Fire Weather Index (FWI), Relative Humidity, Wind vectors, DEM slope, NDVI fuel.

PRESCRIPTION (WHAT ACTION?)

Reinforcement Learning (PPO)

Solves resource allocation: dispatches water-bombers, bulldozers, and containment lines to minimize burned area and human hazard.

# backend/app/rl/suppression_env.py - PPO Policy
import gymnasium as gym

class WildfireSuppressionEnv(gym.Env):
    def step(self, action):
        # Action: [unit_id, target_h3_cell, action_type]
        # action_type: 0=water_drop, 1=cut_fireline, 2=evacuate
        reward = (
            - 1.0 * new_burned_hectares
            - 100.0 * structures_threatened
            - 0.15 * flight_fuel_cost
            + 80.0 * containment_established
        )
        return next_state, reward, done, trunc, info

RL Reward: Penalizes spread to settlements; rewards cutting fire propagation corridors ahead of the flame front.
